# 二、语言模型的发展过程

---

## 1. 统计语言模型（N-gram）

最早的语言模型本质：

> 预测下一个词。

例如：

```text
我今天想去 → 吃饭 / 上班 / 睡觉
```

模型通过统计概率：

```text
P(下一个词 | 前面的词)
```

来预测。

---

## 2. Bigram 示例

语料：

```text
datawhale agent learns
datawhale agent works
```

目标：

计算：

```text
P(datawhale agent learns)
```

根据 Bigram：

```text
P(A B C)
=
P(A)
× P(B|A)
× P(C|B)
```

教程中的计算：

```text
P(datawhale) = 2/6
P(agent|datawhale) = 2/2
P(learns|agent) = 1/2
```

最终：

```text
≈ 0.167
```
---

## 3. N-gram 的缺陷

### （1）数据稀疏

没见过的句子：

```text
agent can learn autonomously
```

概率直接接近 0。

---

### （2）无法理解长距离上下文

例如：

```text
小明把鱼放进冰箱，因为它太臭了
```

“它”指什么？

N-gram 很难理解。

# 三、神经网络语言模型的发展

---

## 1. RNN（循环神经网络）

解决：

> 固定窗口问题。

特点：

- 能记忆历史信息
    
- 顺序处理文本
    
- 有“上下文记忆”
    

但是问题：

- 梯度消失
    
- 长文本遗忘
    
- 训练慢
    

---

## 2. LSTM

LSTM 本质：

> 给 RNN 加“长期记忆”。

核心：

- 输入门
    
- 遗忘门
    
- 输出门
    

解决：

- 长距离依赖问题
    
- 梯度消失问题
    

但仍然存在：

```text
串行计算慢
```

GPU 无法高效并行。

# 五、Attention（注意力机制）

---

## 1. 什么是 Attention

本质：

> 模型决定“应该重点关注哪些词”。

例如：

```text
我喜欢在 bank 边钓鱼
```

模型会重点关注：

```text
钓鱼
```

从而知道：

```text
bank = 河岸
```

而不是银行。 ([Reddit](https://www.reddit.com/r/LLM/comments/1p4h31m/%E7%AC%AC211%E6%9C%9F_%E5%B0%8F%E6%A8%A1%E5%9E%8B%E4%BD%86%E5%A4%A7%E5%BD%B1%E5%93%8D%E5%B0%8F%E5%9E%8B%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%A6%82%E4%BD%95%E9%87%8D%E6%96%B0%E5%AE%9A%E4%B9%89%E7%8E%B0%E5%AE%9E%E4%B8%96%E7%95%8C%E4%B8%AD%E7%9A%84%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD/?utm_source=chatgpt.com "第211期 小模型但大影响：小型语言模型如何重新定义现实世界中的人工智能"))

---

## 2. Self-Attention

Self-Attention：

> 一个词会关注句子里的所有词。

例如：

```text
The animal didn't cross the street because it was tired.
```

模型会学习：

```text
it -> animal
```

---

## 3. QKV（重点）

Attention 三个核心：

|名称|作用|
|---|---|
|Query|我要找什么|
|Key|我是什么|
|Value|我的信息|

Attention 本质：

```text
Query 和 Key 计算相似度
```

再决定：

```text
Value 权重
```

# 六、Transformer 核心结构

---

## 1. Encoder-Decoder

Transformer 原始结构：

```text
Encoder -> Decoder
```

### Encoder

负责：

```text
理解输入
```

### Decoder

负责：

```text
生成输出
```

---

## 2. GPT 为什么只有 Decoder

GPT 是：

```text
Decoder-only
```

因为：

GPT 本质是：

```text
Next Token Prediction
```

即：

```text
预测下一个词
```

---

# 七、Token 概念（非常重要）

---

## 1. 什么是 Token

LLM 不直接理解文字。

它理解的是：

```text
Token
```

例如：

```text
Hello world
```

可能拆成：

```text
["Hello", " world"]
```

中文：

```text
今天天气不错
```

可能：

```text
["今天", "天气", "不错"]
```

---

## 2. 为什么 Token 很重要

因为：

## 上下文窗口 = Token 数量

例如：

|模型|Context|
|---|---|
|GPT-3.5|16K|
|GPT-4|128K|
|Claude 3|200K+|

# 八、Prompt Engineering（提示工程）

---

## 1. Prompt 本质

Prompt：

> 给模型下指令。

模型能力很大程度：

```text
取决于 Prompt
```

---

## 2. Prompt 常见技巧

---

### （1）Role Prompt

```text
你是一名资深 Java 架构师
```

---

### （2）Few-shot

给模型示例。

```text
输入：
A -> B

输入：
C -> D
```

---

### （3）Chain of Thought（CoT）

让模型：

```text
一步一步思考
```

例如：

```text
请逐步分析
```

---

### （4）结构化输出

```text
请使用 JSON 输出
```

Agent 开发里非常重要。

# 九、大模型为什么会“幻觉”

---

## 1. 幻觉本质

LLM：

```text
不是数据库
```

它是：

```text
概率生成器
```

所以：

它会：

```text
“编”答案
```

而不是：

```text
真正理解事实
```

---

## 2. 幻觉来源

### （1）训练数据问题

数据错误。

---

### （2）概率生成

模型只是在：

```text
预测最可能的词
```

---

### （3）知识过时

训练截止后：

```text
模型不知道新信息
```

---

# 十、为什么 Agent 能解决部分幻觉问题

Agent：

```text
LLM + Tool + Memory + Planning
```

例如：

- 搜索引擎
    
- 数据库
    
- Python
    
- 浏览器
    
- API
    

都能：

```text
帮助模型验证事实
```

所以：

Agent 不只是聊天机器人。

而是：

```text
具备行动能力的 AI
```
